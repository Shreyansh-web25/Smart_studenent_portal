# Smart Student Portal

A web-based Student Management System built using Node.js, Express.js, MongoDB, HTML, CSS and JavaScript.

## Features
- Admin Dashboard
- Add New Students
- Edit Student Details
- Delete Student Records
- Search Students
- Attendance Management
- MongoDB Database Integration
- Responsive Design

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

## Installation

1. Download or Clone this Repository.
2. Open the project in VS Code.
3. Open Terminal.
4. Run the following command:

npm install

5. Create a .env file and add:

PORT=5000
MONGODB_URI=mongodb://127.0.0.1:27017/student_portal

6. Start the project:

npm start

7. Open your browser:

http://localhost:5000
